# 📍 تطبيق فروعنا الذكي (Smart Branch Locator Web App)

واجهة موقع ويب فاخرة، فائقة السرعة، وتفاعلية مصممة بالكامل باللغة العربية مع دعم RTL وتصميم متجاوب بنسبة 100% مع شاشات الهواتف الذكية والأجهزة اللوحية وأجهزة الكمبيوتر.

---

## ✨ التحديثات والمميزات الرئيسية للواجهة الجديدة

1. **تصميم عصري بنظام Glassmorphism فاخر:**
   - واجهة مستخدم مبنية بأحدث معايير التصميم العالمي (Soft Shadows, Smooth Borders, Glowing Indicators).
   - خط **Cairo** العربي المتناسق بأوزان دقيقة وأيقونات **Font Awesome 6**.
   - دعم الوضعين الليلي والنهاري (**Dark / Light Theme**) مع حفظ التفضيل تلقائياً في `localStorage`.

2. **حل مشاكل العرض والتجاوب على الهواتف بنسبة 100% (Mobile Perfect):**
   - **Segmented Control Tabs:** شريط تبديل سلس بين [قائمة الفروع] و [الخريطة التفاعلية] على شاشات الموبايل بدون أي مشاكل في إخفاء أو تشويه الخريطة.
   - **Floating Bottom Bar:** شريط تحكم عائم سفلي مريح لليد يتيح التبديل السريع وتحديد الموقع بنقرة زر.
   - منع الزووم التلقائي المزعج في متصفحات الآيفون عبر ضبط أحجام الخطوط في حقول الإدخال.
   - دعم كامل لمساحات الأمان في شاشات الهواتف الحديثة (Safe Area Insets).

3. **شرائح التصفية السريعة والتجربة الفورية (Interactive Chips):**
   - شريط أفقي قابل للتمرير باللمس يضم شرائح سريعة:
     - `جميع الفروع`
     - `الأقرب إليك`
     - `مفتوح الآن`
     - شرائح للمناطق السريعة (مدينة نصر، المعادي، المهندسين، الهرم، التجمع، الشيخ زايد) لتجربة حساب المسافات الفوري دون الحاجة لـ GPS.

4. **تحديد الموقع الذكي (Smart Geolocation):**
   - فحص موقع العميل تلقائياً مع خوارزمية **Haversine Formula** لحساب المسافة الجغرافية الحقيقية بالكيلومتر أو بالمتر.
   - ترتيب القائمة تلقائياً ليكون **الفرع الأقرب في أعلى القائمة** وتمييزه بشارة ذهبية مميزة (`الفرع الأقرب إليك 🌟`).

5. **أزرار التواصل والملاحة المباشرة في كل بطاقة:**
   - **الاتجاهات (Google Maps):** ملاحة فورية بالسيارة أو المشي نحو الفرع.
   - **واتساب (WhatsApp Direct):** فتح محادثة فورية مجهزة برسالة استفسار ترحيبية مهذبة.
   - **اتصال هاتفي مباشر:** نقرة واحدة للاتصال برقم الفرع.
   - **عرض بالخريطة:** تركيز الخريطة على الفرع مع إظهار بطاقة تفاعلية عائمة في أسفل الخريطة.

## 🚀 كيفية تشغيل التطبيق واستخدامه

### الطريقة الأولى (مباشرة):
- انقر نقراً مزدوجاً على ملف [**`index.html`**](file:///d:/WEP/SAT%20MAP/index.html) ليفتح مباشرة في أي متصفح (Chrome, Safari, Edge, Firefox).

### الطريقة الثانية (عبر خادم محلي مثل VS Code Live Server):
- افتح المجلد في **Visual Studio Code**.
- اضغط بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.
