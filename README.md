# 📍 تطبيق فروعنا الذكي (Smart Branch Locator Web App)

واجهة موقع ويب حديثة، سريعة، وتفاعلية مصممة بالكامل باللغة العربية مع دعم RTL وتصميم متجاوب بنسبة 100% مع شاشات الهواتف الذكية وأجهزة الكمبيوتر.

---

## ✨ المميزات الرئيسية للمشروع

1. **دعم كامل للغة العربية (RTL):**
   - واجهة مستخدم مبنية بالكامل لليمين إلى اليسار مع خط **Cairo** الحديث من Google Fonts وأيقونات Font Awesome.
2. **تحديد الموقع التلقائي (Geolocation):**
   - يطلب الموقع تلقائياً بمجرد الدخول لتحديد موقع العميل الجغرافي.
   - يتضمن خياراً ذكياً للمحاكاة والتجربة السريعة (مثل: وسط البلد، مدينة نصر، المعادي، التجمع الخامس، الشيخ زايد) لتجربة حساب المسافات حتى لو تم رفض صلاحية الموقع أو عند التجربة من حاسوب مكتبي.
3. **الترتيب الذكي (Smart Sorting & Distance Calculation):**
   - استخدام معادلة **Haversine Formula** الرياضية لحساب المسافة الجغرافية الحقيقية بين العميل وكل فرع.
   - ترتيب القائمة تلقائياً ليكون **الفرع الأقرب في أعلى القائمة** وتمييزه بشارة ذهبية مميزة (`الفرع الأقرب إليك 🌟`).
4. **تصميم بطاقات عصري (Modern & Sleek Cards):**
   - اسم الفرع، المدينة والمنطقة.
   - العنوان بالتفصيل.
   - مواعيد وساعات العمل مع شارة توضح هل الفرع "مفتوح الآن" أم مغلق.
   - رقم الموبايل مع إمكانية **الاتصال المباشر** (`tel:`).
   - المسافة الدقيقة (بالكيلومتر أو بالأمتار).
5. **الربط المباشر بخرائط جوجل (Google Maps Integration):**
   - زر "الاتجاهات (Google Maps)" يفتح تطبيق أو موقع خرائط جوجل مباشرة بالإحداثيات الدقيقة للتوجيه والملاحة الفورية.
6. **خريطة تفاعلية (Interactive Map):**
   - خريطة مباشرة مدمجة مجانية تماماً باستخدام Leaflet تعرض جميع الفروع، وموقع العميل، وأقرب فرع بألوان وعلامات مخصصة.
7. **ميزات إضافية فاخرة:**
   - التبديل بين الوضع الليلي (Dark Mode) والنهاري (Light Mode) مع حفظ الاختيار.
   - بحث فوري باسم الفرع أو المنطقة.
   - تصفية الفروع المفتوحة حالياً.

## 🚀 كيفية تشغيل التطبيق واستخدامه

### الطريقة الأولى (الأسهل مباشرة):
- انقر نقراً مزدوجاً (Double Click) على ملف `index.html` ليفتح مباشرة في أي متصفح (Google Chrome, Edge, Safari, Firefox).

> **ملاحظة بخصوص صلاحية تحديد الموقع (Geolocation):**
> تطلب بعض المتصفحات تشغيل الملف عبر خادم محلي (Local Server) أو نطاق `https` للسماح بقراءة الـ GPS الحقيقي. لذلك قمنا بتضمين **أزرار المحاكاة التجريبية (Demo Pills)** في أعلى الصفحة، وبمجرد الضغط على أي منطقة (مثل مدينة نصر أو المعادي) ستشاهد إعادة الترتيب وحساب المسافات فوراً!

### الطريقة الثانية (عبر خادم محلي مثل VS Code Live Server):
- افتح المجلد في **Visual Studio Code**.
- اضغط بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.

## ✏️ كيفية تعديل أو إضافة فروع جديدة

يمكنك بسهولة إضافة أو تعديل الفروع عن طريق فتح ملف `app.js`، وستجد مصفوفة البيانات `BRANCHES_DATA` في بداية الملف بالشكل التالي:

```javascript
{
  id: 'nasr-city-1',
  name: 'SAT&IG Bookstore Nasr City',
  city: 'القاهرة',
  area: 'مدينة نصر',
  address: 'مدينة نصر، القاهرة (Main Branch)',
  phone: '01281847737',
  lat: 30.059075,   // خط العرض من خرائط جوجل
  lng: 31.334630,   // خط الطول من خرائط جوجل
  workingHours: '7:00 ص - 12:00 منتصف الليل',
  isOpen: true
}
```

للحصول على إحداثيات أي فرع جديد:
1. افتح **Google Maps**.
2. انقر بزر الفأرة الأيمن على موقع الفرع.
3. انسخ الرقمين (خط العرض `lat` وخط الطول `lng`) وضعهما في الكود.
